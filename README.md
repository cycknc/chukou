## 檔案說明
- `index.html`：整個網站（文字、價格、日期、樣式、功能都在這個檔案裡）
- `img/`：各課程照片與插圖（`xxx_1.webp` 是封面，`xxx_1_t.webp` 是封面縮圖）
- 根目錄的 `.webp`：首頁封面、標誌、「認識觸口的生物」圖卡

## 如何更新內容
1. 到本儲存庫，點 `index.html` → 右上角鉛筆圖示（Edit）。
2. 按 `Ctrl + F`（Mac 為 `⌘ + F`）搜尋要改的課程名稱。
3. 找到該課程後，修改對應欄位（見下表），再按右上角「Commit changes」。
4. 約 1–2 分鐘後，網站就會更新。

| 欄位 | 意思 | 範例 |
|---|---|---|
| `n:` | 課程名稱（不要改，圖片與標籤是用名稱對應的） | `n:'特派任務'` |
| `p:` | 價格 | `p:'$480/人（含午餐）'` |
| `date:` | 日期（共學選修日、營隊） | `date:'5/8（六）'` |
| `d:` | 課程簡介 | `d:'……'` |
| `o:[…]` | 學習目標（每一項用單引號包起來，逗號分隔） | |
| `m:[…]` | 時間、人數上限等小標籤 | `['3 / 4.5 小時','上限 60 人・2 班']` |

注意：
- 文字都放在 `'單引號'` 裡面。要改內容時，只改引號內的字，不要刪掉引號、逗號或括號。
- 引號內如果要再用單引號，請改用「」或全形的 ’。
- 年度日曆的日期在 `var EV=[` 那一段。
- 「DIY」「實驗/操作」標籤的課程名單在 `var DIYN=` 與 `LABN=` 兩行。
- 「認識觸口的生物」連到 TBN 的網址在 `var TBN={` 那一段。

## 如何更換或新增照片
1. 在儲存庫進入 `img` 資料夾 → Add file → Upload files。
2. 照片請先縮小（寬度約 960 px、檔案 200 KB 以內，格式 webp）。
3. 新增照片後，需要在 `index.html` 的 `IMG=` 那一段加上檔名，才會顯示。這一步較複雜，建議交給熟悉的夥伴處理。

## 修改後出錯怎麼辦
在 GitHub 進入 `index.html` → History，可以看到每一次修改，選擇前一個版本即可還原。
